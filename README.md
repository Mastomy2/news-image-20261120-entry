## The image

`image.png` (1024×1024) is a newspaper-style poster: a navy
masthead naming the day, then **35 stories from 7 regions** in a
dense grid — five stories per region, each numbered, with its source.
Round 3 rebuilds the poster from scratch after checking every story
against live reporting. Round 2 had 8 stories; the rank-1 entry
carries 35 stories across 7 regions, so round 3 matches that breadth
while keeping every figure traceable to a named source. Items marked
"Thu 19 Nov" happened Thursday and dominated Friday's news cycle;
everything else is Friday 20 November.

## How it works

`main.py` (Python 3.13, standard library only, no network) copies
`image.png` to `/output/entry.png`. Before copying it checks the file
is a genuine PNG of 1024×1024, and after copying it verifies the
output's SHA-256 and size match the source, then prints the hash and
size — so every run writes byte-identical output.

```bash
python3 main.py   # writes /output/entry.png
```
